## akceo decks

The slide decks here are Markdown files that [akceo](https://github.com/LunarCommand/akceo)
builds into single HTML files. If you're an AI agent writing or editing one:

- Before you start, run `akceo docs --print` and read the whole guide it prints. It's long, so if
  your tool cuts the output short or saves it to a file, read that file to the end.
- After every edit, run `akceo check <deck>.md` and fix what it reports.
- To write the HTML file, run `akceo build <deck>.md`.
